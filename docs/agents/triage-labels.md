# Triage Labels

| Label in mattpocock/skills | Label in our tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an AFK agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

## Workflow states

`Status:` may also record workflow progress. Wayfinding tasks use `open`, `claimed`, and `resolved`; `open` is available to the frontier, `claimed` marks active work, and `resolved` marks completed work. Keep resolved issues resolved when documentation is updated.

| Workflow state | Meaning |
| --- | --- |
| `open` | Awaiting an agent and eligible for the frontier when unblocked |
| `claimed` | An agent is actively working on the issue |
| `resolved` | Work is complete |
