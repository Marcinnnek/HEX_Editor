# 14: Configurable comparison colors

**What to build:** Let users choose legible comparison-difference colors separately for Light and Dark and save them through Preferences.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Preferences offers separate swatches and a picker for unequal bytes, bytes only in A, and bytes only in B in each appearance mode.
- [ ] Selecting a palette to edit does not switch the application's active theme before Save.
- [ ] Save persists and applies the selected colors; Cancel and X discard unsaved choices, including choices made after a theme switch.
- [ ] Reset restores defaults for the palette currently being edited without changing the other palette until Save.
- [ ] Compare uses the chosen colors, and the default Dark colors keep all three difference states distinguishable.
