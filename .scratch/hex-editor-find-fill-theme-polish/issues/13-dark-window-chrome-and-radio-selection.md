# 13: Dark window chrome and appearance selection

**What to build:** Make native window title bars and Preferences' appearance selection reflect the effective theme clearly throughout the application.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Every existing and newly opened application window uses a dark native title bar in Dark and a light title bar in Light.
- [ ] Follow Windows updates title bars when the system theme changes without restarting or reopening dialogs.
- [ ] The selected appearance radio button shows a visible indicator in Dark; Light remains readable.
- [ ] Existing Save, Cancel, and X behavior in themed dialogs remains unchanged.
