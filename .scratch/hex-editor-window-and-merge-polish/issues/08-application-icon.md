# 08: Application icon

**What to build:** Use the supplied HEX Editor icon consistently in Windows and application-owned windows.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] The Windows executable contains the supplied icon resource and displays it in Explorer and taskbar representations.
- [ ] The main window and application-owned dialogs use the same icon in Light and Dark themes.
- [ ] Existing window controls and dialog behavior remain unchanged while the icon is applied.
- [ ] Build-artifact inspection and representative rendered WPF scenarios verify the icon; native file-picker chrome remains controlled by Windows.
