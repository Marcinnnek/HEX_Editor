# 03: Compare Block lists

**What to build:** Show the same one-line Block list in both Compare columns, with each image's Blocks above its own data and full descriptions accessible in narrow panels.

**Blocked by:** 02: Editor Block list.

**Status:** ready-for-agent

- [ ] Both Compare lists use the established Block sentence, hexadecimal and decimal length format, and ascending numbering.
- [ ] Each list remains aligned with its own image and stays above that image's HEX/ASCII data.
- [ ] Long entries remain on one line and are fully reachable by horizontal scrolling in either narrow Compare column.
- [ ] Selecting a Block navigates to its start in the relevant image without changing the editable base/reference roles.
- [ ] Ctrl/Shift can select multiple base-image Blocks for the existing selected-segment export operation.
- [ ] Rendered WPF scenarios verify both columns, scrolling, navigation, and selection with separated memory segments.
